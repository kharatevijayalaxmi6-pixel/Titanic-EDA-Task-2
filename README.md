# Task 2: Exploratory Data Analysis (EDA)

## Objective
The objective of this task is to perform Exploratory Data Analysis on the Titanic dataset to understand patterns, trends, and relationships between different features.

## Dataset
Titanic dataset (cleaned dataset from Task 1).

- Total rows: 721
- Total columns: 10

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## EDA Steps Performed

1. Loaded and inspected the dataset.
2. Generated summary statistics using Pandas.
3. Created histograms to understand data distributions.
4. Created boxplots to identify potential outliers.
5. Created a pairplot to explore relationships between features.
6. Performed survival analysis based on Sex and Passenger Class.
7. Compared Age and Fare distributions by survival.
8. Created a correlation matrix and heatmap.
9. Calculated survival rates by Sex and Passenger Class.
10. Identified important patterns and trends.

## Key Findings

- Female passengers had a higher survival rate than male passengers.
- First-class passengers had better survival outcomes than third-class passengers.
- Fare showed a positive relationship with survival.
- Sex showed the strongest correlation with survival among the features examined.
- The overall survival rate in the cleaned dataset was approximately 33.70%.

## Conclusion
Exploratory Data Analysis helped identify important patterns and relationships in the Titanic dataset. Sex, Passenger Class, and Fare showed noticeable associations with passenger survival.
